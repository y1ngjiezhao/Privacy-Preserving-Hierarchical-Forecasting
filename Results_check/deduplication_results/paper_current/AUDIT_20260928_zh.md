# Manuscript and source-result consistency audit (2026-09-28)

This file translates the historical audit record. It does not report a new audit or new experiment runs.

## Findings

The audit inspected 20 existing directories under the manuscript outputs and 40
historical DP table snapshots, tracing source results for the text included by the
current main.tex. Historical backups are not expected to match current results
verbatim: most contain earlier text, metrics, or experiment configurations. The
main result tables and four current DP numerical tables matched the corresponding
active results in the source directories.

Two substantive version inconsistencies were found and fixed:

1. The manuscript used residual covariance estimation without noise variance
   correction, while the default covariance notebook still called the old corrected
   configuration. PPHF_modules/dp_fhf/notebook_runtime.py, the notebook, and its
   generation template were updated to pass --no-debias explicitly and write to
   <dataset>/no_debias/. Historical defaults of the lower-level CLI/API were retained,
   and the documentation specified --no-debias for the current manuscript.
2. The 0.05% retention fraction was changed to 0.5% on September 14. Source code,
   matrices, and numerical tables were updated, but the text retained the old count
   of 348 truncated eigenvalues. Recalculation using the existing code and training
   residuals confirmed the current counts of 63 for MinTs and 65 for WLSv. Only
   those numbers and their method labels were replaced in the text, and the
   commented old appendix copy was also corrected. Correct source results were
   not reverted to the old configuration.

## Validation evidence recorded at the time

- 1182 checks of tables, rankings, parameters, per-node means, and coverage passed.
- Recalculation of 12 main-text configurations with the current dp_covariance.py
  and original training residuals reproduced all 24 P/W matrix pairs.
- Executing the corrected default covariance entry point reproduced four runs
  covering two datasets and two base-forecast branches. The maximum metric
  difference was approximately 4.04e-12, within numerical precision; see
  default_notebook_reproduction.json in the full local audit archive.
- 17 related unit/integration tests passed, covering the no-debias default, output
  separation for explicit corrected runs, and existing DP-FedAvg and sweep
  reconciliation tests.
- All input hashes matched across 142 historical input/code hash checks. Historical
  sweep implementation hash differences matched the recorded output-path migration.
  The notebook entry-point change received a new source hash without rewriting
  historical manifests.
- Actual release-coordinate sensitivity was 248350 coordinates with mean
  2211.7818244982914 for GEF, and 1261440 coordinates with mean 1.7339416381047428
  for Ausgrid, matching 2211.782 and 1.734 in the manuscript.
- The manuscript compiled successfully to 36 pages. The correction on page 26
  was checked for clipping and layout overflow.

## Active entry points and files

Results_check/paper_current/README.md was added to the source project as an index
of current manuscript results. Its CSVs export unrounded source values, with only
display names synchronized. PPHF_modules/results_check/audit_paper_results.py can
be rerun after later manuscript or result changes; failed validation prevents CSV
re-export.

In the full local audit archive, before/ retains the pre-change source code,
documentation, notebooks, relevant covariance artifacts, and manuscript.
backup_inventory.json and dp_table_snapshot_history.json record existing backups;
audit/ stores individual checks; covariance_reproduction.json and
provenance_verification.json record independent recalculation and provenance.
These generated audit artifacts are not included in this code-and-data snapshot.

No models were retrained. Retired manuscript tables, corrected controls, old 0.05%
data, and presentations were not used to overwrite current source results. Theory
and prose unrelated to numerical synchronization were not rewritten.
